## Part 1 — AIと音楽業界の「これまでの実績」（事実ベース）

### 1-1. 市場と供給量

| 指標 | 数値 |
|---|---|
| AI in music 市場規模 | 2025年 44.8億ドル → 2026年 55.5億ドル（CAGR 23.7%）※定義次第で19.8億〜66.5億ドルと大きくブレる |
| 生成AI音楽（狭義） | 2026年 9.6億ドル → 2030年 27.9億ドル（CAGR 30.4%） |
| AI完全生成のアップロード比率 | 2025年1月 1万曲/日 → 2026年4月 約7.5万曲/日（**全アップロードの44%**、Deezer検出） |
| 実際の再生比率 | アップロード28%時点で、**Deezerの全ストリームのわずか0.5%** |
| 将来予測 | 2028年に世界ストリーミング収益の20%がAI生成（CISAC） |

**読み取り**: 供給は爆発したが、需要はまったく追随していない（44%作られて0.5%しか聴かれない）。
つまり「曲を作れること」の価値はほぼゼロになり、**「聴かれる理由」＝文脈・人格・共同体だけが希少資源**になった。

### 1-2. 実際に結果を出したAIアーティスト（実績）

| アーティスト | 実績 | 構造 |
|---|---|---|
| **Xania Monet** | Billboard R&B Digital Song Sales 10位以内 / 総合 Digital Song Sales 22位 / Spotify 単曲250万再生 / Hallwood Media と最大300万ドルの契約（争奪戦の末） | 詩人 Talisha Jones が**自分の詞**を Suno で楽曲化。声と絵はAI、**言葉と人生は人間** |
| **Velvet Sundown** | Spotify 月間リスナー 140万人超 | 「正体不明の謎バンド」という物語そのものが拡散装置になった |
| **Breaking Rust** | Billboard チャート入り | 同上（AIカントリー） |

**共通点**: 音の良さで勝ったケースは一つもない。**「AIが作った」という事実が話題の燃料になり、その裏に人間の物語がある**という構造で勝っている。
逆に言えば、この「AIだから話題」というボーナスは既に飽和しつつあり、後追いでは効かない。

### 1-3. 権利・法務（2025→2026の決着）

- 2025年10月: **UMG × Udio 和解**。2025年11月: **WMG × Suno 和解**（訴訟取り下げ＋ライセンス提携）。WMG × Udio も和解。
- Suno / Udio は既存モデルを**2026年中に廃止**し、**ライセンス済み学習データのみの新モデル**へ移行。
- Udio は既にダウンロード・書き出し不可の「壁に囲まれた庭」に変質。
- **UMG と Sony は Suno と係争継続**（2026年4月時点で交渉決裂）。
- **JASRAC（2026年6月ガイドライン）**: 人間の創作的寄与が認められない作品は**著作物に当たらず管理不可**。AI作曲＋人間作詞なら**詞のみ管理**。JASRACの調査ではクリエイターの**54%がAI学習利用に反対**、著作権法30条の4改正とオプトアウト導入を正式要求。

**読み取り**: 「AIで作った曲は自分の著作物として管理・保護できない可能性がある」というのが日本の実務上の現在地。カタログを資産として積むなら、人間の寄与を証明できる形で作る必要がある。

### 1-4. プラットフォーム規制 ← **KNZに直接効くのはここ**

| プラットフォーム | 2026年時点のルール |
|---|---|
| **Bandcamp**（KNZの販売先） | 2026年1月、**「全体または実質的な部分がAIによって生成された音楽・音声は許可しない」**。他アーティストの**作風の模倣**にAIを使うことも禁止。**ステム分離・ボーカル修正・AIマスタリングは対象外＝使用可**。ユーザー通報→人間が審査→削除（カタログ削除の実例あり） |
| **Spotify** | DDEX規格でのAI利用開示を採用。AI利用そのものでは down-rank しないと明言。ただし**2026年8月から「AIペルソナ」アーティストにラベル付与＋デフォルトでレコメンド対象外**、認証バッジも対象外 |
| **Deezer** | 完全AI生成曲はエディトリアル・プレイリストとアルゴリズム推薦から除外。AI補助は可（要開示） |

**読み取り**: 業界の線引きは「AI生成（＝排除・非推薦）」vs「**AI補助（＝完全に容認）**」で確定した。この線をどちら側で立つか自分で宣言することが、そのまま流通量になる。

### 1-5. 逆張り（人間製）側の実績

- Bandcamp Friday: 2026年の初回だけで**360万ドル**、2020年開始以降の累計**1億5000万ドル超**。
- **Bandcamp直販 ＋ ストリーミング**の組み合わせは、ストリーミング単独に比べ総収益が**30〜45%増**（Chartlex のキャンペーンデータ）。
- Cyndi Lauper、Bonnie Raitt ら**800人近いアーティストが反AI公開書簡**に署名。スウェーデンはAI補助曲を公式チャートから除外。
- イラスト領域では Cara のような「AI投稿禁止」プラットフォームにクリエイターが移動。

**読み取り**: 「人間が作った」ことが**課金される記号（プレミアム）**になり始めている。これは供給過剰の必然的な裏返し。

## Part 2 — 構造の要約（3行）

1. **生成は無料になった。希少なのは文脈・人格・儀式。**
2. **プラットフォームは「完全AI」を推薦から外し、「AI補助」は罰しない。** どちら側に立つか宣言した者だけが流通に乗る。
3. **成功事例は例外なく「人間の物語」を持っている。** 音質でも量でもない。

## Part 3 — KNZ への提案

### 現状の資産（サイト・公開情報から確認できるもの）

- 名義: KNZ／宇宙音楽実験家・Dance Music Producer、Base: Japan、Since: 2026、Style: Underground Beats
- 世界観: **Nature × Machine ∞ Universe** / GANJALIEN（GANJA × ALIEN） / 麻の葉文様 / アシッドグリーン / sacred geometry
- チャネル: SoundCloud・Bandcamp・Instagram（すべて `knzooooooooom`）
- リリース: **1本**（SIGNAL / KNZ x ZNK, 2026, Digital Single）
- 自社資産: 公式サイト（日英対応、FANS登録→Googleスプレッドシート自動蓄積、問い合わせ、隠し音声認証「ケンズーム」）
- 未着手: グッズ（Coming soon）、動画（準備中）、**Spotify / Apple Music などのDSP配信**

### 提案A — ポジショニング: 「AI補助・人間製」を**明文化して武器にする**（最優先・今週やる）

KNZの世界観はすでに **Nature × Machine**。つまり「AIを敵にも神にもしない第三の立場」がコンセプトと完全に一致している。ここは作れる差別化ではなく、**すでに持っている差別化**。

**やること**: サイトに `PROTOCOL`（制作原則）を1枚追加し、何にAIを使い、何を人間だけでやるかを公開する。

例（叩き台。Kenzoさんの実際の制作に合わせて調整）:
```
MACHINE（AIに任せる）  : マスタリング補助 / ステム分離 / アートワークの下地 / 翻訳
HUMAN（人間だけでやる）: 作曲・編曲・演奏・声・ミックスの判断・世界観の決定
NEVER                  : 既存アーティストの作風の模倣 / 完全AI生成のトラック
```

**効果は3つ同時**:
1. **Bandcamp規約リスクの事前回避**（KNZの唯一の販売チャネル。通報→審査→カタログ削除の実例がある）
2. **Spotify の DDEX 開示にそのまま流用可能**（＝AIペルソナ・ラベルを回避し、推薦対象から外れない）
3. **「信念体系の提示」としてファンの自己定義装置になる**（Cult Creatives Phase 3。保存・シェアされるのはこの手の宣言）

すでに Profile の Tools 欄が「脳/手/口/目/足/PC/地球」となっていて、実質この宣言が始まっている。**これを1ページに拡張するだけ**。

### 提案B — システム: 90日で 0 → 1000（Cult Creatives Phase 2）

| 月 | やること | KNZ固有の中身 |
|---|---|---|
| **第1月: 土台とバンキング** | 発信を始める前に**30本分の素材を先に貯める** | PROTOCOL公開／制作風景・フィールド録音・幾何学ビジュアルをまとめ撮り／リリースを**月1本**に固定 |
| **第2月: 発信と最適化** | 毎日出す。**指標はフォロワー数ではなく「保存」と「シェア」** | 2026年のショート動画は「編集型ミーム」化が主戦場。縦型でGANJALIEN世界観を出す |
| **第3月: 部族化と体験** | 呼称・シンボル・儀式を与える | ファンの呼称を **GANJALIEN** に確定／麻の葉＝所属の記号／FANS登録者限定の「緑の光」配信（未発表曲）を定期化 |

コンテンツ・バケツ（4分類）案:
1. 制作過程（Machine：機械の反復運動）
2. 自然・幾何学のフィールド録音／映像（Nature）
3. GANJALIEN の物語・信念（Universe＝世界観）
4. ライブ／DJ／現場

### 提案C — 流通と収益

1. **DSP配信を開始する**（現在SoundCloud＋Bandcampのみ＝発見される導線がほぼゼロ）。配信時に**DDEXでAI利用を開示**。
2. **Bandcamp Friday（毎月）に合わせた限定リリース**を組む。直販比率を上げると総収益が30〜45%変わる根拠がある。
3. **グッズの「Coming soon」を埋める**。麻の葉文様の実物（Tシャツ／インセンス／ステッカー）は「所属の記号」として機能し、Cult化の装置とグッズ収益を兼ねる。
4. **サイトのFANSリストが最大の資産**。プラットフォーム規約が変わっても消えないのはここだけ。全導線の終着点をFANS登録に統一する。

### 注意点（1つだけ）

大麻・ヘンプ関連の視覚表現は **Meta / Google の広告審査で落ちやすく、アカウント側のリーチ制限も受けやすい**。
→ **有料広告を戦略の柱にしない**。オーガニック（ショート動画）＋直販（Bandcamp）＋メルマガ（自社リスト）の3本で組む。これは制約ではなく、そもそも Cult Creatives の推奨経路と同じ。
